# 공용 과제 제출 준비본

이 폴더는 selfishclub/baemin-ops-os-camp에 제출할 문서의 보관본입니다. 공용 저장소 반영 완료를 의미하지 않습니다.
GitHub 연결 앱의 공용 저장소 쓰기가 403 Resource not accessible by integration으로 거부되어 브라우저 전환 승인을 기다립니다.

제출 경로: 02_실전캠프_Day2_실습제출/4조_박가영_가영이네/
문서는 같은 상대 경로로 반영하고, 이 개인 저장소의 프로젝트 소스와 dist 자산은 해당 폴더의 v2/프로젝트/에 넣습니다. .git, node_modules, .env, .vercel, submission 폴더는 중복 포함하지 않습니다.
기존 v1과 다른 수강생 폴더는 보존합니다. Vercel v2 배포와 실제 첫화면 PNG는 아직 보완 중입니다.
