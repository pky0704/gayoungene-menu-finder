# Gayoungene Menu Finder

가영이네 외국인 고객이 사진·가격·재료를 보고 메뉴를 고르는 정적 웹사이트입니다. 영어, 일본어, 중국어(간체)를 제공하고 한국어 메뉴명을 함께 표시합니다.

## v2 구현 범위
- 사용자 입력 시트 기준 실제 메뉴 32개, 원본 사진 18장. 사진이 없는 14개는 준비 중으로 표시합니다.
- 떡볶이·라볶이 → 튀김 → 김밥·식사류 → 순대 → 사이드 → 빙수 → 음료 순서입니다.
- 추천 7종에 오렌지 별과 번역된 추천 문구를 표시합니다.
- 확인된 재료만 오렌지 아이콘으로 표시합니다. 맵지 않음·맵기 미확인에는 고추가 없고, 약간 매움은 1개, 매움은 2개입니다.
- Find a menu의 맵기·나라별 추천 교집합, 결과 수, 초기화, 상세 정보, 사진 확대, 직원에게 보여주기를 지원합니다.
- PC는 왼쪽 카테고리와 사진/설명 좌우 배치, 모바일은 세로 배치와 접는 카테고리입니다.
- 메뉴 / 이용 방법 / 매장 정보로 나누어 선결제·셀프 서비스·영업시간을 안내합니다.

## 실행 및 검사
Node.js 22 이상 권장. 정적 파일은 dist/에 있으며 빌드는 필요 없습니다.

```sh
npm ci
npm test
npm run dev
```

npm test는 데이터 검사와 jsdom 상호작용 검사를 실행합니다. jsdom은 실제 브라우저 렌더링을 검증하지 않습니다.
Vercel은 Other 프레임워크, Build Command 비움, Output Directory dist로 배포하며 vercel.json에 설정을 보존했습니다. 환경변수와 데이터베이스는 필요 없습니다.

## 데이터 및 확인이 필요한 사항
- Google Sheets 자동 연결이 아닌 2026-10-02 수동 반영 스냅샷입니다. 데이터는 dist/data.js, UI 문구는 dist/i18n.js에서 관리합니다.
- 오뎅만 떡볶이(M008), 재주문100% 단무지(M033)는 제외했습니다.
- 식재료 아이콘은 확인된 포함 정보입니다. 아이콘이 없다고 해당 재료가 없다는 뜻은 아닙니다. 가공품·소스까지 미포함이 확인된 메뉴가 없어 재료 제외 버튼 11개는 안내와 함께 비활성화했습니다.
- 맵기 선택은 정확히 해당 단계만 표시합니다. 전체 레시피/교차 접촉/알레르기 안전을 보증하지 않습니다.
- 추천 7종은 사장님 지정입니다. 나라별 추천은 별도 관찰 데이터이며 순위나 매출 분석 결과가 아닙니다.
- M018과 M019 사진은 원본 시트에 연결된 파일이 동일합니다. 서로 다른 사진으로 교체하려면 원본이 필요합니다.
- 번역은 원어민 최종 검수 전입니다. 실제 외국인 고객 사용 횟수·시간 절감 효과는 측정하지 않았습니다.
- 주문·결제·장바구니·고객정보 수집·추적·재고 관리 기능은 없습니다.
- 선택적 WebMCP 기능은 브라우저가 지원하는 경우에만 등록됩니다. 실제 지원 브라우저 검증 전이며 maxSpice는 최대 맵기 의미를 유지합니다.

## 디자인과 자산
오렌지 #FF6600과 공식 원본 로고를 사용합니다. WithGreen/SORENA의 빠른 메뉴 파악 방식에서 큰 사진·가격·식재료 아이콘 구성을 참고했습니다. 원본 사이트의 코드·사진을 복제하지 않았습니다.

메뉴 사진은 사용자가 승인한 원본 18장입니다. 로고는 변형하지 않았습니다. 공유 이미지는 공식 가로 로고를 원본 비율로 흰 여백 안에 배치했습니다. 아이콘 라이선스는 dist/icon-credits.txt 및 동봉한 라이선스 문서를 참조하세요. 예전 AI 매장 이미지와 7개 언어 브랜드 문구는 보관 자산이며 현재 화면에 표시하지 않습니다. SB어그로 웹폰트는 번들에 포함하지 않았으며 시스템 글꼴을 사용합니다.

## 첫 고객 사용 준비 (2026-10-03)

사장님 확인 기준으로 아직 QR·링크를 손님에게 안내하지 않았고 실제 고객 사용·성과 기록은 없습니다. 맵기 빠른 선택, 사용 가능한 필터 우선 배치, 메뉴 카드의 직원용 화면 바로가기를 추가했습니다.
매장용 A5 QR 안내물은 launch/menu-qr-a5.pdf, QR 원본은 launch/menu-qr.png, 첫 사용 기록 양식은 launch/first-use-notes.txt에 있습니다. 인쇄 후 휴대폰으로 주소와 언어 선택을 확인하고 매장에 부착하세요. 번호는 사이트 안내용이며 주문기기와 같다고 보장하지 않습니다.


2026년 10월 3일 피드백·QA 반영

첫 화면의 Help me choose에서 맵기를 고르면 기존 메뉴 중 최대 3개를 보여 줍니다. 사장님 지정 추천을 우선하며, 전체 메뉴의 나라별 필터와 별도로 동작한다고 안내합니다. 계절 메뉴·디저트·음료는 이 추천에서 제외합니다. 사진·가격·한국어 이름을 확인하고 직원용 화면으로 이동할 수 있습니다.
재료 제외 검색은 계속 비활성화합니다. 대신 손님이 직접 고른 재료 질문을 한국어로 직원에게 보여 줄 수 있습니다. 이 화면은 미포함이나 알레르기 안전을 확정하지 않습니다.
메뉴 번호는 안내 번호로 표시합니다. 키오스크 번호와의 일치는 확인되지 않았습니다.
QA의 1만 원 조합 상황은 기존 메뉴 가격을 읽는 검사로만 사용했습니다. 자동 조합·예산 추천 기능은 포함하지 않았습니다.
기존 noindex를 해제하고 canonical, robots.txt, sitemap.xml을 추가했습니다. 검색 등록·노출·순위는 확인되지 않았습니다.
가상 QA 기록은 사용메모.md, 화면 증거와 브라우저 검사 스크립트는 launch/qa-feedback/에 있습니다.


2026년 10월 4일 사용성 개선

첫 화면의 중복 언어 선택을 줄이고 재료 문의 버튼을 간단 추천 옆에 배치했습니다. 선택된 맵기·나라 필터를 접힌 검색창 밖에서도 확인하고 하나씩 해제할 수 있습니다. 재료 미확인 안내는 각 메뉴의 식재료 아이콘 옆에 표시합니다. 영어 메뉴 설명 4개를 쉽게 다듬었으며 가격·재료·사진 등 나머지 메뉴 정보는 동일합니다.
검수 기록은 사용메모.md와 REVIEW.md, 화면 및 브라우저 검사는 launch/qa-followup-20261004/에 있습니다. 실제 휴대폰·원어민·실제 고객 검수는 여전히 남아 있습니다.
