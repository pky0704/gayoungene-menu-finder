# Gayoungene Menu Finder

가영이네 외국인 고객이 사진·가격·재료를 보고 메뉴를 고르는 정적 웹사이트입니다. 영어, 일본어, 중국어(간체), 베트남어, 몽골어, 인도네시아어, 프랑스어를 제공하고 한국어 메뉴명을 함께 표시합니다.

## v2 구현 범위
- 사용자 입력 시트 기준 실제 메뉴 32개, 원본 사진 18장. 사진이 없는 14개는 준비 중으로 표시합니다.
- 떡볶이·라볶이 → 튀김 → 김밥·식사류 → 순대 → 사이드 → 빙수 → 음료 순서입니다.
- 추천 7종에 오렌지 별과 번역된 추천 문구를 표시합니다.
- 확인된 재료만 오렌지 아이콘으로 표시합니다. 맵지 않음·맵기 미확인에는 고추가 없고, 약간 매움은 1개, 매움은 2개입니다.
- 독립된 나라별 추천과 Find a menu의 맵기·재료 조건을 함께 적용합니다. 국기를 누르면 결과로 이동하며, 초기화·상세 정보·사진 확대·직원에게 보여주기를 지원합니다.
- PC는 왼쪽 카테고리와 사진/설명 좌우 배치, 모바일은 세로 배치와 접는 카테고리입니다.
- 메뉴 / 이용 방법 / 매장 정보로 나누어 선결제·셀프 서비스·영업시간을 안내합니다.

## 실행 및 검사
Node.js 22 이상 권장. 정적 파일은 dist/에 있으며 빌드는 필요 없습니다.

```sh
npm ci
npm test
npm run dev
```

npm test는 데이터 검사와 jsdom 상호작용 검사를 실행합니다. jsdom은 실제 브라우저 렌더링을 검증하지 않습니다.
Vercel은 Other 프레임워크, Build Command 비움, Output Directory dist로 배포하며 vercel.json에 설정을 보존했습니다. 환경변수와 데이터베이스는 필요 없습니다.

## 데이터 및 확인이 필요한 사항
- Google Sheets 자동 연결이 아닌 2026-10-02 수동 반영 스냅샷입니다. 메뉴 사실은 dist/data.js에 보존하고 설명형 메뉴명·추가 번역은 dist/menu-translations.js에서 적용합니다. UI 문구는 dist/i18n.js와 dist/i18n-extra.js에서 관리합니다.
- 오뎅만 떡볶이(M008), 재주문100% 단무지(M033)는 제외했습니다.
- 식재료 아이콘은 확인된 포함 정보입니다. 아이콘이 없다고 해당 재료가 없다는 뜻은 아닙니다. 재료 제외 버튼 11개는 선택할 수 있습니다. 현재 취향 검색은 확인된 포함 재료 및 일반 조리법상 포함 가능성이 있는 재료를 제외합니다. 나머지는 미포함이 확인되지 않은 후보이며 확인 필요 안내를 함께 표시합니다. 전체 원재료·알레르기 안전 검색이 아닙니다. 추정 데이터와 근거는 dist/ingredient-guidance.js 및 INGREDIENT-REVIEW.md에서 관리합니다.
- 맵기 선택은 정확히 해당 단계만 표시합니다. 전체 레시피/교차 접촉/알레르기 안전을 보증하지 않습니다.
- 추천 7종은 사장님 지정입니다. 나라별 추천은 별도 관찰 데이터이며 순위나 매출 분석 결과가 아닙니다.
- M018과 M019 사진은 원본 시트에 연결된 파일이 동일합니다. 서로 다른 사진으로 교체하려면 원본이 필요합니다.
- 번역은 원어민 최종 검수 전입니다. 실제 외국인 고객 사용 횟수·시간 절감 효과는 측정하지 않았습니다.
- 주문·결제·장바구니·고객정보 수집·추적·재고 관리 기능은 없습니다.
- 선택적 WebMCP 기능은 브라우저가 지원하는 경우에만 등록됩니다. 실제 지원 브라우저 검증 전이며 maxSpice는 최대 맵기 의미를 유지합니다.

## 디자인과 자산
오렌지 #FF6600과 공식 원본 로고를 사용합니다. WithGreen/SORENA의 빠른 메뉴 파악 방식에서 큰 사진·가격·식재료 아이콘 구성을 참고했습니다. 원본 사이트의 코드·사진을 복제하지 않았습니다.

메뉴 사진은 사용자가 승인한 원본 18장입니다. 로고는 변형하지 않았습니다. 공유 이미지는 공식 가로 로고를 원본 비율로 흰 여백 안에 배치했습니다. 아이콘 라이선스는 dist/icon-credits.txt 및 동봉한 라이선스 문서를 참조하세요. 예전 AI 매장 이미지와 7개 언어 브랜드 문구는 보관 자산이며 현재 화면에 표시하지 않습니다. SB어그로 웹폰트는 번들에 포함하지 않았으며 시스템 글꼴을 사용합니다.

기존 noindex를 해제하고 canonical, robots.txt, sitemap.xml을 추가했습니다. 검색 등록·노출·순위는 확인되지 않았습니다.

2026년 10월 4일 초기 7개 언어 복원과 설명형 메뉴명

초기 PRD의 영어·일본어·중국어·베트남어·몽골어·인도네시아어·프랑스어를 확인하고 사용자 요청에 따라 네 언어를 추가했습니다. 기존 3개 언어 이름도 음식 종류와 조리법 중심으로 다듬었습니다. 32개 메뉴의 이름·설명·수량, 필터, 추천, 직원용 화면, 재료 질문, 매장 안내, 지도, 이벤트가 7개 언어에서 동작합니다.
예: 김말이는 Crispy Seaweed & Glass Noodle Roll, 김밥은 Egg & Vegetable Seaweed Rice Roll, 순대는 Steamed Korean Sausage, 인절미빙수는 Soybean Rice Cake & Red Bean Shaved Ice로 설명합니다. 밀떡 선택을 쌀떡으로 단정하지 않고 떡볶이는 Rice or Wheat Cakes로 표시합니다. 한국어 주문명과 메뉴 번호는 유지합니다.
메뉴 사실과 번역을 분리했습니다. dist/data.js의 승인된 스냅샷에 dist/menu-translations.js의 이름·추가 언어 문구를 적용합니다. UI 추가 언어는 dist/i18n-extra.js입니다. 기존 3개 언어에만 고정되어 있던 추천 배지도 번역 키로 변경했습니다. 7개 언어 버튼은 가로 스크롤 없이 줄바꿈합니다.
320px 몽골어에서 두 줄 탐색 메뉴와 카테고리 바가 겹치는 문제를 실제 브라우저에서 발견했습니다. 모바일 탐색 높이와 카테고리 고정 위치를 맞춰 수정했습니다.
원어민 검수·모든 외국인의 이해 여부 확인은 미완료입니다. 새 언어의 하단 안내에 원어민 미검수 초안임을 표시했습니다. 번역 검수 전까지 미확인 식재료를 확정하거나 알레르기·채식·할랄 적합성을 안내하지 않습니다. 매장 주문기기의 지원 언어는 기존 영어·일본어·중국어 그대로이며 사이트 언어 확장과 별개입니다.
