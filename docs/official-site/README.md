# 코덱스에서 가영이네 공식 사이트 개발 시작하기

정리일: 2026-10-04
저장소: https://github.com/pky0704/gayoungene-menu-finder
인수인계 브랜치: codex/official-site-plan-20261004
기준 코드: c3fd0a369d5b0b27b7ff738b50b6da6668253fba

이 폴더는 가영이네 공식 사이트를 개발하기 위한 인수인계 문서다. 원본 채팅과 기획 페이지에 접근하지 못해도 핵심 요구와 개발 순서를 읽고 작업할 수 있다. 현재 저장된 것은 기획과 실행 계획이며 새 공식 사이트는 아직 구현하지 않았다.

## 읽을 순서

1. 저장소 루트 AGENTS.md: 최신 메뉴 사이트의 운영 기준.
2. [PRD.md](PRD.md): 브랜드 이야기, 기능, 다국어, 디자인, 완료 기준.
3. [IMPLEMENTATION.md](IMPLEMENTATION.md): 현재 코드에 맞춘 6단계 실행 계획.
4. [ASSETS-AND-GATES.md](ASSETS-AND-GATES.md): 사용 가능한 자료와 공개 전 확인 항목.

기존 메뉴 7개 언어·3개 탐색은 기존 메뉴 서비스의 범위다. 새 공식 사이트는 한국어 포함 9개 언어·6개 탐색을 적용하면서 기존 메뉴 링크와 프랑스어 접근을 유지한다. 자료의 사실, 최신 코드의 사용자 변경, 새 공식 사이트의 범위를 구분한다.

## 코덱스에 붙여넣을 시작 지시문

```text
가영이네 공식 사이트 개발을 시작해 줘.
저장소: pky0704/gayoungene-menu-finder
시작 브랜치: codex/official-site-plan-20261004

AGENTS.md와 docs/official-site/의
README.md, PRD.md, IMPLEMENTATION.md,
ASSETS-AND-GATES.md를 먼저 읽어 줘.

위 PRD와 실행 계획을 기준으로
별도 구현 브랜치에서 순서대로 개발해 줘.
기존 메뉴 사이트와 QR 링크를 보존하고
dist/official/에 공식 사이트를 추가해 줘.

브랜드 이야기를 중심에 두고
메인 컬러 #FF6600을 꼭 사용해 줘.
전체 9개 언어 전환을 구현해 줘.

준비된 자료로 화면과 기능을 완성하고
미확인 후기·사진·선결제 정보는 만들지 마.
자료 공백 때문에 가능한 개발까지 멈추지 말고
공개 전에 필요한 항목으로 따로 기록해 줘.

기존 테스트와 실제 브라우저 검증을 수행하고
검토 가능한 미리보기와 변경 내용을 보여 줘.
주요 단계마다 커밋하고 작업 브랜치에 저장해 줘.
```

위 지시문을 코덱스에 전달하는 시점에 사용자가 이 문서의 실행을 요청한다. 인수인계 문서 자체를 자동 실행 승인이나 도메인 결제 지시로 해석하지 않는다. 현재 대화의 요구는 문서 준비까지다.

## 현재 확인 결과

- 원격 main의 c3fd0a3까지 확인하고 문서 브랜치를 최신 코드 위로 옮겼다. 최신 메뉴명·글자 크기·재료 취향 검색과 추정/미확인 구분을 인수인계 문서에 반영했다.
- 기존 데이터 검사 12개는 통과했다.
- 전체 npm test는 jsdom 미설치로 UI 검사 단계에서 중단됐다. 코드 실패로 확정한 것이 아니며, 개발 환경에서 npm ci 후 다시 실행해야 한다.
- 새 공식 사이트의 기능·번역·브라우저 검사는 아직 수행할 구현이 없어 미실시다.
- 이번 변경 파일은 이 폴더의 Markdown 문서 4개다. 제품 코드·배포 설정은 수정하지 않았다.
- 전용 writing-plans 스킬은 현재 환경에 없어 실행 계획을 직접 작성했다.
