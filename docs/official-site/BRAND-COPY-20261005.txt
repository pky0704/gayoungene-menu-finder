이름은 딸,
얼굴은 엄마.

가게를 준비하던 가영은 엄마의 사진을 보고 로고를 직접 그렸습니다. 그래서 가영이네는 딸의 이름으로 불리고, 엄마의 얼굴로 손님을 맞습니다. 함께 만든 가게라는 이야기가 이름과 얼굴에 고스란히 담겨 있습니다.

오래 해온 손맛에,
새로 배운 것을 더합니다.

엄마의 감각을 기록하고, 손님들의 반응을 살피며 메뉴와 운영을 다듬습니다. 배움이 수료증으로 끝나지 않고 가게의 하루로 이어지도록, 모녀는 지금도 공부합니다.

배운 것을 가게의 하루로

배민아카데미에서 글쓰기와 가게 운영을 배우고, 손님과 소통하는 방법을 고민합니다. 가영의 배민프렌즈 활동도 더 나은 가게를 위한 배움의 과정입니다.

직접 만들고, 직접 등록한 이름

이름과 로고를 기획한 가영은 가영이네 상표등록도 직접 진행해 마쳤습니다. 우리 가게만의 얼굴과 이야기를 꾸준히 가꾸어갑니다.

적용 범위와 확인 사항
홈의 브랜드 문구를 한국어·영어·중국어 간체·일본어·베트남어·몽골어·태국어·러시아어·인도네시아어에 반영했습니다. 통합 메뉴의 가게 소개도 맞추었고, 기존 프랑스어 메뉴 소개를 포함해 10개 언어를 유지했습니다. 외국어는 원어민 검수 전입니다.

자료 근거는 docs/official-site/PRD.md와 기존 승인 콘텐츠, 메뉴 데이터입니다. 2012년은 어머니가 직원으로 분식 일을 시작한 해이며 가영이네 개업은 2022년 2월 12일입니다. 어머니와 딸이 매장 운영을 함께한다는 사실을 유지했습니다.

기존 32개 메뉴의 이름·가격·재료·맵기와 알레르기 안내, QR 연결은 보존했습니다. 고객 후기 원문과 사용 범위, 조리 과정 사진, 실제 가맹 모집 여부·비용·조건은 확인 대기입니다. 새로운 후기·별점·수익 수치·인증 주장은 추가하지 않았습니다. 영업시간과 이벤트의 실제 운영 변경 여부를 새로 확인한 기록은 아닙니다.

검수와 배포
주황색 띠의 검정 문구가 왼쪽으로 끊김 없이 반복 이동합니다. 멈춤·재생, 키보드 조작, 언어 전환 중 멈춤 유지도 확인했습니다. 동작 줄이기 설정 대응은 코드에 반영했으나 OS 설정을 바꾼 실제 실행은 확인하지 않았습니다.

홈 9개 언어를 320·390·820·1024·1280px 목표 폭의 45개 화면에서 확인했습니다. 배율에 따른 실제 측정 폭은 검수 JSON에 남겼습니다. 통합 메뉴 소개 10개 언어도 390px에서 확인했습니다. 가로 넘침, 16px 미만 표시 글자, 로드된 이미지 깨짐을 점검했고 관찰한 브라우저 실행 오류는 없었습니다. npm test, 공식 빌드·불변조건 및 변경 JavaScript 구문 검사를 통과했습니다.

로컬 미리보기에 반영했습니다. 공개 Vercel 배포는 기존 인증 대기로 완료되지 않았으며 공식 도메인 설정은 변경하지 않았습니다.
