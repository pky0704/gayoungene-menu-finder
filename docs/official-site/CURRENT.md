추가 자료: 말랑가영이 매장 커튼 포스터는 원본 그대로. 포스터는 실제 사람이 없는 캐릭터 일러스트로 시각 확인했지만, 공개 GitHub 업로드가 자동 승인 검토에서 고객 사진 가능성을 이유로 거절되어 사이트 배포용 비공개 로컬 자산에 보존했다. 공개 GitHub에는 올리지 않는다. Git만으로 빌드하면 메인 이미지는 공식 로고로 대체되고 캐릭터 포스터는 생략된다. 실제 사진까지 포함한 배포는 로컬에서 Vercel build 후 prebuilt 결과물을 검수하여 업로드한다. 수료증은 학습의 기록으로 소개하고, 상표는 ‘상표등록’으로 정확히 표현한다. 등록증 번호·개인 주소 등 세부정보는 재게시하지 않는다. 매장 전경 사진 중 포스터 가격·개인정보가 섞인 넓은 사진은 사용하지 않는다.

공식 로고의 직접 손그림 이력을 후속 모든 캐릭터의 제작 방식으로 확대하지 않는다. 포스터의 SINCE 2012에는 어머니의 경력 시작이며 매장은 2022년 개점이라는 번역 설명을 붙인다.
