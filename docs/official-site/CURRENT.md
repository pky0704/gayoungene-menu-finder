npm test의 데이터 12개 검사와 기존 DOM 상호작용 검사, 공식 빌드·불변조건·19개 정적 페이지 검사, 변경 JavaScript 구문 검사를 통과했다. 기존 dist 메뉴와 승인 사진의 원본 바이트 보존도 확인했다. 새 정적 페이지 검사는 공식 SNS 링크, 외부 선결제, 언어별 국기, 읽을 수 있는 본문, 메뉴 가격과 구조화 데이터 일치를 검사한다.

실제 Codex 앱 브라우저에서 320·390·820·1280px 목표 폭으로 홈 9개와 메뉴 10개 언어의 76개 화면을 확인했다. 가로 넘침, 16px 미만 표시 텍스트, 로드 완료한 이미지의 깨짐, undefined 문구를 발견하지 못했다. 러시아어 홈 첫 관찰은 자바스크립트 전환 전 한국어를 읽어 재검사했고 러시아어 표시를 확인했다. 추가로 1024px 러시아어 홈 헤더를 검사했다. 배율 반올림으로 일부 실제 치수는 목표값과 1~2px 차이가 나며 원시 기록에 실측값을 남겼다.

추천 문답의 최대 3개 제안, 일본 추천 3개와 결과 초점, 나라 다시 선택, 돼지고기 제외 후 23개 결과와 접힌 상태의 주의 안내, 메뉴 상세 재료, 프랑스어 전환과 한국어 직원 화면의 3,900원 가격, 모바일 카테고리 접힘, 홈 언어 전환, 방문 안내 5개 펼침, 원형 국기와 PC TOP을 직접 확인했다. 별도 official/tests/browser.cjs는 새 선택자로 보완했지만 CLI로 실행하지 않았다. 해당 스크립트 실행과 실제 앱 브라우저 관찰을 구분한다.

검수 증거는 official/qa/unified-brand-20261005/에 Git 제외로 보관한다. 이번 작업은 가상 사용자의 실제 반응이나 구매율을 측정한 결과가 아니다. 실제 휴대폰·Safari, 원어민 번역, 운영 기록·신청·결제 완료, 미제공 국내외 후기의 원문·사용 범위는 미확인이다. 기존 후기 링크는 유지했다. 가맹 준비 여부를 확인 대기 콘텐츠로 노출하지 않으며 사용자의 요청에 따라 가맹 영역 자체를 제거했다.

공개 배포

기존 gayoungene-official 프로젝트를 확인했으나 Vercel API가 gayoungene 팀에 대한 403 권한 오류를 반환했다. 해당 팀 접근이 가능한 계정으로 연결을 다시 인증해야 재배포할 수 있다. 이번 변경은 로컬 미리보기 반영이며 공개 배포 완료가 아니다. 도메인·DNS는 변경하지 않았다.
