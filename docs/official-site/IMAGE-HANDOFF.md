# 이미지 적용 기준

최신 사용자 선택과 현재 파일은 [CURRENT.md](CURRENT.md) 및 [official/README.md](../../official/README.md)에 정리했다.

1. 공식 로고 원본 그대로 사용. 로고·메뉴 사진·포스터를 자르거나 다시 그리지 않는다.
2. 2022 매장 사진에는 역사 사진과 당시 가격임을 캡션에 명시한다.
3. 주황 가게 앞 합성 이미지 등 이전 생성 일러스트 3종은 모두 제외한다.
4. 사용자가 선택한 실제 사진의 고객 얼굴을 비식별 처리한 편집본을 사용하고 AI 편집 사실을 알린다. 모녀와 손님을 식사하는 새 장면으로 합성하지 않는다.
5. 원본 고객 사진은 배포나 공개 GitHub에 포함하지 않는다. 사이트용 모녀 사진과 편집본은 Git 제외 폴더에서 빌드에만 포함한다.
6. 수료증은 교육 이력, 상표등록은 브랜드를 직접 가꾼 이력으로 소개한다. 음식 품질 인증·특허로 바꾸어 부르지 않는다.
7. 말랑가영이 포스터 원본을 사용한다. 토끼는 원본 확보 전 임의 캐릭터를 대신 만들지 않는다.
