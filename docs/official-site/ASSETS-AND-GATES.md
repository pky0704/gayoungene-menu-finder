2026-10-04 데스크탑 작업 기준. CURRENT.md에 현재 구현·검수·배포 상태를 기록한다.

사용 가능한 자료
공식 로고 원본, 메뉴 사진 18장, 2022년 매장 사진, 사이트 공개가 승인된 모녀 사진·원본 말랑 가영이 포스터·교육 수료증 사진을 확보했다. 최신 캐릭터 가이드를 참고한 일반 말랑 가영이와 혀 없는 밝은 미소의 동물 짝꿍 토끼 개별 이미지도 로컬에 준비했다. 토끼 모자를 쓴 가영이와 동물 토끼를 구별한다.

보관과 공개 범위
승인된 사진과 캐릭터 실사용본은 official/private-assets에 보관하고 빌드 시 허용된 여섯 파일만 포함한다. Vercel 공식 사이트 공개와 공개 GitHub 저장은 별개다. 사진·파생 이미지·참고 자료·검수 화면·배포 묶음·인증 정보는 GitHub에 올리지 않는다. 공식 로고와 승인 사진은 원본 바이트를 유지한다.

제외 자료
고객 사진 및 고객 사진에서 만든 모든 편집본은 공개 동의가 없으므로 이번 사이트에 사용하지 않는다. 거절된 합성 고객 이미지도 제외한다. 기존 자료 목록에 비식별 편집본이 적혀 있어도 사용 승인을 뜻하지 않는다.

확인 대기
국내외 고객 후기 원문과 사용 범위, 실제 조리 과정 사진, 번역 원어민 검수가 필요하다. 인용문·별점·국적·방문일·음식 안전 주장은 만들지 않는다. 후기 확인 전에는 실제 Google 지도 후기 링크를 유지한다.

배포와 도메인
기존 gayoungene 팀의 gayoungene-official 프로젝트에 재배포할 준비를 마쳤다. 현재 Vercel 인증이 필요하며 재배포 완료로 간주하지 않는다. 사용자의 임시 URL 검수 후 gayoungene.com 연결 및 실제 Vercel 안내값에 따른 Namecheap DNS 설정을 진행한다.
